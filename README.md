# Pokédex React Challenge

Uma aplicação React que consome a PokeAPI para listar Pokémon com tema claro/escuro.

## 🚀 Funcionalidades

- Listagem de Pokémon com paginação (Carregar mais)
- Página de detalhes do Pokémon
- Tema claro/escuro com Context API
- Design responsivo
- Navegação entre páginas com React Router

## 🛠️ Tecnologias Utilizadas

- **React.js** - Biblioteca principal
- **Styled Components** - Estilização com temas
- **React Router DOM** - Navegação
- **Axios** - Requisições HTTP
- **Context API** - Gerenciamento de estado do tema
